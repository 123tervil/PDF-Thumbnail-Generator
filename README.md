# PDF Thumbnail & Mockup Generator

A simple browser-based tool for turning PDF pages into customizable, high-resolution image thumbnails and mockups.

## Features

- Export the first page, all pages, or a custom page range
- Choose a canvas layout, background, spacing, and image resolution
- Save as PNG, JPEG, or WebP, or download all pages in a ZIP file

## Usage

Open `ThumbnailGen.html` in a modern web browser, upload or drag in a PDF, choose your options, and download the generated images. PDF.js and JSZip are loaded from public CDNs, so an internet connection is required.
